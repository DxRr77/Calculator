# Проект: Инженерный мультифункциональный калькулятор (Engineering Calculator)

## 📝 Описание проекта
Данный проект представляет собой "Инженерный калькулятор", разработанный на языке Python с использованием принципов объектно-ориентированного программирования (ООП). Проект создан для проведения комплексных математических вычислений.

Инструмент решает задачи из пяти разных областей математики: базовой арифметики, тригонометрии, численного интегрирования, линейной алгебры (матрицы) и графического анализа. Калькулятор снабжен **единой системой ведения истории**, которая автоматически фиксирует выполненные действия.

---

## 🛠 Описание блоков кода и методов классов

### 1. Класс `History` (Система логирования)
Отвечает за сбор данных, хранение и вывод истории операций.
* `add_records(category, operation, result)` — добавляет новую запись в историю (сохраняет в виде словаря с ключами категории вычисления, самого выражения и полученного ответа).
* `show()` — выводит всю историю вычислений на экран. Метод автоматически проверяет категорию операции: если выводится матрица, она разворачивается в красивый наглядный столбик с помощью встроенной подфункции `to_matrix_stack(matrix_obj)`.
* `clear()` — полностью очищает список истории, возвращая его к исходному пустому состоянию.

### 2. Класс `BasedCalculator` (Базовая арифметика)
Реализует основные арифметические действия.
* `AddOperation(a, b)` — метод сложения двух чисел.
* `SubOperation(a, b)` — метод вычитания второго числа из первого.
* `MulOperation(a, b)` — метод умножения двух чисел.
* `DivOperation(a, b)` — метод деления. Включает в себя проверку на равенство переменной `b` нулю. Если `b == 0`, генерируется исключение `ValueError`.

### 3. Класс `TrigCalculator` (Тригонометрический блок)
Вычисляет значения тригонометрических и обратных функций. Поддерживает умный анализ входящих параметров: если передана строка со знаком градуса (например, `"90°"`), метод конвертирует её в радианы, иначе обрабатывает число как радианы.
* `_parse_input(x)` — внутренний метод класса для проверки и перевода входных аргументов из градусов в радианы.
* `SinOperation(x)` / `CosOperation(x)` — методы вычисления синуса и косинуса угла `x`.
* `TanOperation(x)` / `CotOperation(x)` — методы вычисления тангенса и котангенса угла `x` с проверкой на существование значения функции в заданной точке.
* `AsinOperation(x, to_degrees=False)` / `AcosOperation(x, to_degrees=False)` — методы вычисления арксинуса и арккосинуса. Дополнительный параметр `to_degrees` позволяет получить итоговый ответ сразу в градусах.
* `AtanOperation(x, to_degrees=False)` / `AcotOperation(x, to_degrees=False)` — методы вычисления арктангенса и арккотангенса с опциональным переводом ответа в градусы.

### 4. Класс `IntegrationCalculator` (Численное интегрирование)
Вычисляет определенные интегралы геометрическим путем.
* `IntegrateOperation(func, a, b, n=1000)` — метод вычисления определенного интеграла на отрезке от `a` до `b` методом трапеций с количеством разбиений `n`. Метод работает с любыми переданными математическими функциями (включая встроенные, объявленные пользователем, такие как `func1`–`func5`(func1 = x**2 + 3*x; func2 = x**2 + 3*x + 1; func3 = x**3 - 2*x + 5; func4= math.sin(x) + math.cos(x); func5 = 2*x**2 - 4*x + 1), или `lambda`-функции).

### 5. Класс `MatrixCalculator` (Линейная алгебра)
Предназначен для проведения математических операций над матрицами.
* `_validate_matrix(matrix, name="Матрица")` — внутренний метод валидации структуры, проверяющий, что матрица не пуста, имеет строго прямоугольную/квадратную форму и состоит исключительно из чисел.
* `_same_size(A, B)` — внутренняя проверка равенства размерностей двух матриц.
* `add_matrices(A, B)` / `subtract_matrices(A, B)` — методы поэлементного сложения и вычитания двух матриц одинаковой размерности.
* `multiply_by_scalar(matrix, scalar)` — метод умножения элементов матрицы на число (скаляр).
* `multiply_matrices(A, B)` — метод перемножения двух матриц (строка на столбец) с контролем согласованности их размеров.
* `transpose(matrix)` — метод транспонирования (отражения матрицы относительно главной диагонали).
* `determinant(matrix)` — метод рекурсивного расчета определителя квадратной матрицы любого размера через поиск миноров и алгебраических дополнений подфункцией `_det(m)`.
* `inverse(matrix)` — метод нахождения обратной матрицы через вычисление детерминанта и присоединенной матрицы.
* `_det_without_history(matrix)` — скрытый метод расчета определителя, используемый внутри вычисления обратной матрицы, чтобы промежуточные расчеты подматриц не засоряли общую историю.

### 6. Класс `InteractiveGraphCalculator` (Визуализация функций)
Управляет интерактивным построением графиков функций на базе библиотек `numpy` и `matplotlib`.
* `PlotOperation(*functions)` — метод, принимающий неограниченное количество строковых выражений (например, `"x**2 - 4"`, `"np.sin(x)"`) и инициализирующий графическое окно.
* `prepare_data()` — выполняет парсинг и безопасное вычисление строк функций через `eval()` на массиве точек `x`. Регистрирует успешные построения или ошибки в историю проекта.
* `update_graph()` — перерисовывает координатную плоскость, отображая графики по отдельности или выводя их все вместе на экран.
* `on_key(event)` — обработчик клавиатуры. Позволяет циклически переключаться между графиками в окне по нажатию клавиши **Пробел**.

### 7. Класс `EngineeringCalc` (Главный управляющий класс)
Является фасадом приложения. Он объединяет в себе все независимые модули калькуляторов и связывает их с общим объектом истории вычислений `History`.
* `show_history()` — метод-мост, запрашивающий отображение накопленного лога операций.
* `clear()` — метод-мост, отправляющий команду на очистку истории.

## 🚀 Стек технологий проекта
* Язык программирования: **Python 3**.
* Математические вычисления: встроенная библиотека **`math`**.
* Генерация координатных сеток функций: библиотека **`numpy`**.
* Построение интерактивных интерфейсов графиков: библиотека **`matplotlib.pyplot`**.
